# 다국어 UI

현재 `app/`은 한국어(`ko`)와 영어(`en`)를 지원한다. 이전 `src/` 프로토타입과 개발용 비교 페이지는 한국어로 유지한다.

## 언어 선택

우선순위는 주소의 `?lang=ko` 또는 `?lang=en`, 저장된 선택(`localStorage.locale`), 기본값 영어 순서다. 처음 방문하면 브라우저 언어와 관계없이 영어를 쓴다. 상단 언어 선택은 화면을 다시 불러오지 않고 문구와 도시 이름을 바꾼다. 시뮬레이션 상태·카메라·발생원 설정은 유지하며, 선택은 브라우저와 주소에 저장한다. 공유 링크에도 현재 언어가 들어간다. 저장소가 차단돼도 주소와 언어 전환은 동작한다.

## 문구 추가

- `app/src/i18n/ko.ts`에 의미를 나타내는 키를 추가한다. 한국어 사전에서 `MessageKey` 타입을 만든다.
- `app/src/i18n/en.ts`에 같은 키의 영어를 추가한다. 누락되거나 잘못 추가한 키는 타입 검사에서 잡힌다. 언어별 `{parameter}` 이름은 같아야 하며 단위 테스트에서 비교한다.
- 정적 HTML은 `data-i18n="key"`를 쓴다. 자식 요소가 있는 라벨은 번역할 부분만 `<span>`으로 감싼다. 접근성 이름은 `data-i18n-aria-label`, 메타 설명은 `data-i18n-content`를 쓴다.
- 동적 텍스트는 `text('elementId', () => t('key', { parameter: value }))`로 등록한다. 콜백을 언어 변경 때 다시 실행하므로 화면을 재생성할 필요가 없다. 문자열 조각의 순서를 연결하기보다 완전한 문장과 보간 변수를 사전에 둔다.
- HTML 문구는 `html('elementId', () => th('key', params))`로 등록한다. 태그는 신뢰하는 사전에만 두고, `th`는 전달받은 값을 이스케이프한다. 도시 이름처럼 HTML에 직접 넣는 외부 데이터는 `escapeHtml`을 사용한다.
- 프레임마다 갱신하는 표시나 통계는 `onLocaleChange`에서도 갱신한다. 언어 변경 경로에서 계산 초기화나 발생원 재생성을 호출하지 않는다.
- 화면 숫자와 경과 시간은 `formatNumber`, `formatClock`을 사용한다. URL, 셰이더, CSS 좌표와 계산용 숫자는 번역하지 않고 기존 숫자 직렬화를 유지한다. 단위는 두 언어 모두 SI 단위를 쓴다.

## 도시와 오류

`npm run data:cities`가 Natural Earth 원자료의 한국어·영어 이름을 함께 저장한다. `cities.bin` 버전 2는 기존 다섯 필드 뒤에 `nameEn`을 붙인 형식이다. 영어 이름이 없는 구버전 자료도 원래 이름으로 표시할 수 있다. 도시 라벨과 영향 도시 목록은 같은 언어의 이름을 사용한다.

지원하지 않는 WebGL2·부동소수점 렌더 타깃 오류는 `LocalizedError`로 표시한다. 그 밖의 시작·준비 오류는 번역된 안내를 보여주고 원래 진단 정보는 콘솔에 남긴다.

## 새 언어 추가

새 사전을 `Record<MessageKey, string>` 형식으로 추가하고, `app/src/i18n/index.ts`의 언어 타입·사전 등록·Intl 로케일·언어 해석을 확장한다. `app/index.html`의 언어 선택에는 해당 언어의 자칭 이름을 추가한다. 도시 이름의 추가 번역이 필요하면 자료 생성기와 `CityLayer.setLocale`도 확장한다.

## 확인

```bash
npm run app:build
npm test
npm run test:e2e -- tests/e2e/i18n.spec.ts tests/e2e/globe.spec.ts
```

검사 항목은 사전 키·보간 변수 일치, 언어 선택 우선순위, 시간·숫자 형식, HTML 이스케이프, 영어 지진·소행성 화면, 실시간 언어 전환 후 계산 상태 유지, URL·저장소 복원, 모바일 화면 폭, 저장소 차단 상황이다. 기존 한국어 시나리오는 URL 또는 저장된 선택으로 한국어를 명시한다. 다국어 검사는 한국어 브라우저에서도 첫 방문은 영어인지 확인한다.
