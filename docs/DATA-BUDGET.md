# 다운로드 예산

클라이언트가 받는 양의 **항목별 상한**이다. 상한을 넘기는 변경은 합치지 않는다. 근거가 된 실측값은 [측정 기록](DATA-MEASUREMENTS.md)에, 방향은 [결정 이력](decisions/DECISIONS.md) D-013~D-015에, 작업 순서는 [계획](PLAN.md)에 있다.

단위는 압축 후 전송 바이트(gzip)다.

## 1. 첫 화면

사용자가 아무것도 고르지 않아도 받는 양이다.

| 항목 | 상한 | 근거 |
|---|---|---|
| 코드 (JS, CSS, HTML) | 200 KB | 현재 실측 29 KB(지구, 지형 생성, 지진과 소행성, 중첩 격자 계산, 침수 표시 포함. WebGL2 직접 사용). three.js를 쓰면 160 KB |
| 전 지구 격자 39 km (지구 표시와 전 지구 계산 겸용) | 450 KB | 현재 실측 423 KB |
| 실제 경계선 110m (해안선, 국경) | 60 KB | 실측 27 KB. Natural Earth |
| 주요 도시 1,990곳 | 80 KB | 실측 31 KB. Natural Earth |
| 글꼴, 이미지, 지도 타일 | 0 | 시스템 글꼴을 쓴다. 지도 이미지는 없다 |
| **합계** | **650 KB** | 현재 실측 약 488 KB. 프로토타입 2는 4.1 MB였다 |

## 2. 기본 모드의 시나리오 하나

동의 없이 받는 양이다. 모두 우리 빌드 결과물에서 받는다.

| 항목 | 상한 | 근거 |
|---|---|---|
| 10 km 조각, 동작 하나당(한 곳을 끝까지 확대하거나 시나리오 하나를 시작할 때) | 320 KB | 조각 평균 32 KB. 확대 실측 51~167 KB, 도호쿠에서 센다이까지 시나리오 시작 실측 167 KB(발생원과 해안 격자가 같은 조각을 쓴다). 해안이 발생원과 멀면 최대 8개를 더 받는다 |
| 실제 경계선 50m, 화면 폭 2,500 km 아래로 확대할 때 한 번 | 300 KB | 실측 196 KB |
| **한 세션 누적 (첫 화면 포함)** | **1.25 MB** | 첫 화면 457 KB + 확대 한 번과 시나리오 하나의 조각 약 330 KB + 50m 경계선 196 KB. 50m 경계선을 더하며 1 MB에서 올렸다(2026-09-22). 조각은 캐시에 남아 같은 바다에서 다시 돌리면 추가 0 |

## 3. 상세 모드

사용자가 따로 고르고, 안내를 읽고 동의한 뒤에만 받는다. 브라우저가 공개 지형 타일 서버에서 직접 받는다.

| 항목 | 상한 | 근거 |
|---|---|---|
| 연안 격자용 타일, 최대 4장 | 500 KB | 실측 1.2~1.9 바이트/셀, 타일당 최대 125 KB |
| 중간 격자용 타일, 최대 9장 | 1,000 KB | 같은 근거 |
| **합계** | **1.5 MB** | |

안내 화면에는 실제 타일 수로 계산한 예상치를 보여 준다. 예상치가 상한을 넘으면 격자를 줄인다.

## 4. 빌드 결과물 전체

정적 호스팅에 올리는 총량이다.

| 항목 | 상한 | 근거 |
|---|---|---|
| 전 지구 격자 39 km, 파일 1개 | 0.45 MB | 실측 426 KB |
| 전 지구 격자 10 km, 256 px 조각 160개 | 5.2 MB | 현재 실측 4.98 MB. 조각 평균 32 KB, 최대 51 KB |
| 실제 경계선 110m, 50m과 주요 도시 | 0.4 MB | 실측 254 KB |
| 코드 | 0.8 MB | 압축 전 기준 |
| **합계** | **7 MB** | 현재 빌드 폴더 실측 5.8 MB |

세밀한 연안 자료는 빌드에 넣지 않는다. 넣으면 0.5 GB를 넘는다(측정 기록 4절).

## 5. 확인 방법

- 전송량: `tests/e2e/globe.spec.ts`가 첫 화면 전송량을 재고 상한을 넘으면 실패한다. 외부 서버로 나가는 요청이 있어도 실패한다. 항목별 내역은 `node dev/shoot-app.mjs`가 출력한다.
- 빌드 총량: 빌드 폴더의 크기를 잰다.
- 자료 파일은 생성 스크립트(`npm run data:earth`)가 크기를 출력하고, 상한을 넘으면 실패한다.
