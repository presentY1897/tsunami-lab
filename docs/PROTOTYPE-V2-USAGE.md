# 프로토타입 2 실행과 구현

2026-09-21에 종료한 `src/` 프로토타입의 설명이다. 프로토타입의 코드는 2026-10-01에 저장소에서 지웠다(D-047). git 태그 `prototype-v2`에 마지막 상태가 있다. 아래 명령은 그 태그를 받아야 돈다. 아래 기능과 측정값은 당시 기준이며, 현재 `app/`의 기능은 [README](../README.md), 남은 작업은 [계획](PLAN.md)을 본다. 방향을 바꾼 이유는 [프로토타입 2 정리](PROTOTYPE-V2.md)에 있다.


## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run check      # 타입 검사 + 단위 테스트 + 빌드
npm run test:e2e   # 헤드리스 브라우저 검증 (처음이면 npx playwright install chromium)
```

주소에 `?preset=tohoku2011&quality=low&autorun=1`을 붙이면 바로 시작한다. 프리셋 ID는 `src/app/scenario.ts`에 있다.

## 사용 흐름

1. 2D 지도에서 발생원(빨간 핀)과 관측 해안(파란 핀)을 놓는다. 프리셋 5종이 있다. 지진은 해저 경사를 읽어 단층 방향을 자동으로 잡는다.
2. 시작하면 지형 타일을 받아 격자를 만들고 3D 장면으로 넘어간다.
3. 파도가 바다를 건너는 동안은 거친 격자만 빠르게 돌린다. 파도가 관측 해안에 다가오면 세밀 격자가 깨어나고 시점이 해안으로 옮겨 간다.
4. 침수 면적, 최대 침수심, 처오름 높이, 내륙 침투 거리, 첫 침수 시각, 관측 지점 수위 그래프가 나온다. 지도에는 최대 침수심, 도달 시간, 최대 유속을 칠해 볼 수 있다.

## 계산 구조

| 단계 | 방법 |
|---|---|
| 격자 | Web Mercator 픽셀에 정렬한 중첩 격자 3~4단계. 바다 전체 약 2 km, 중간 약 250 m, 관측 해안 약 30 m |
| 지형 | AWS Terrain Tiles(Terrarium). 육지는 z11~12, 수심은 z10에서 가져와 합성 |
| 지진 | Strasser 외(2010) 스케일링, 해구 쪽에 몰린 미끄러짐 분포, Okada(1985) 연직 변위. 육지 표고에도 반영 |
| 소행성 | Collins 외(2005) 수중 크레이터, 부피 보존 공동, Ward & Asphaug 1/r 감쇠 보정 |
| 전파와 침수 | 비선형 천수방정식. 엇갈린 격자, 풍상 면 수심, 젖음/마름, Manning 마찰. WebGL2 셰이더 |
| 중첩 | 단방향. 자식 경계 20셀에서 부모 값으로 완화 |
| 렌더링 | three.js. 지형과 수면이 계산과 같은 표고 텍스처를 읽는다 |

설계 근거는 [결정 이력](decisions/DECISIONS.md), 작업 현황은 [TASK 인덱스](tasks/README.md), 통과 기준은 [품질 게이트](tasks/QUALITY-GATES.md)에 있다.

## 알려진 한계

1. 공개 지형 자료의 연안 수심은 약 2 km 해상도다. 항만과 만의 세부 지형이 없다.
2. 육지 표고(SRTM)는 건물과 나무 높이가 섞인 표면 모형이고 오차가 수 m다. 작은 쓰나미의 침수 범위는 믿기 어렵다.
3. 방파제와 제방이 없다. 세밀 격자에서 해수면보다 낮은 저지대는 0.2 m로 평평해진다.
4. 쇄파와 분산을 계산하지 않는다. 소행성 파고는 상한에 가까운 추정이다.
5. 실제 GPU에서의 성능은 아직 재지 않았다. 검증은 헤드리스 소프트웨어 렌더러에서 했다.
6. 방재 판단용이 아니다.
