# 프로토타입 2 정리

이 문서는 2026-09-21에 `src/` 프로토타입 2를 종료하며 남긴 기록이다. 아래 상태·측정값·미완료 항목은 당시 기준이다. 현재 개발 대상은 `app/`이며, `tests/`와 `dev/`에는 현재 앱의 검사도 함께 있다. 현재 기능은 [README](../README.md), 남은 작업은 [계획](PLAN.md), 이전 프로토타입 실행법은 [실행과 구현](PROTOTYPE-V2-USAGE.md)을 본다.

당시에는 제품의 방향을 확인하지 않고 만들어 계획과 어긋났다. 개발을 멈추고 가져갈 부분과 다시 만들 부분을 아래처럼 정리했다.

- 프로토타입 1: 단일 HTML 2D 시뮬레이터 (동해·일본 해구, 선형 방정식 + 경험식 침수)
- 프로토타입 2: 이 코드. 3D, 중첩 격자, 비선형 방정식으로 침수 직접 계산, WebGL2

## 다음 단계의 지침 (2026-09-21, 사용자)

목표: 시뮬레이터로 쓰나미를 일으키고 그 영향을 시각화한다.

1. **모바일 폰에서도 돌아가야 한다.**
2. **지도는 실제 지도 이미지를 입히지 않는다.** 삼각형이나 마름모 면으로 표현하고, 색 등으로 육지와 바다를 구분하며, 같은 면으로 높낮이도 표현한다.
3. **서버는 정적 파일만 준다.** 전부 서버에 올려 웹으로 접근하는 상황을 가정한다. 클라이언트가 받는 양이 많으면 안 되므로 꼭 필요한 양을 계산해서 정한다. 실측은 [측정 기록](DATA-MEASUREMENTS.md), 상한은 [다운로드 예산](DATA-BUDGET.md)에 있다.

## 가져갈 것

검증이 끝났고 지침과 충돌하지 않는 부분이다.

- `src/physics`: Okada 변위, 단층 스케일링과 불균일 슬립, 소행성 공동과 사전 보정, 발생원 래스터화, CPU 기준 솔버
- `src/gpu`: 셰이더와 다단계 솔버. CPU 기준과 0.000003 m 차이로 일치. WebGL2라 모바일 브라우저에서도 돈다(실측은 필요)
- `src/geo/mercator.ts`, `grid.ts`, `domain.ts`: 좌표와 격자 계획. 격자를 자료 덩어리 경계에 맞추는 기능만 더하면 된다
- `tests/`, `dev/gpu-check.*`, `dev/measure-network.mjs`

물리와 셰이더를 합쳐 gzip 7 KB다.

## 버릴 것

- `src/picker`: MapLibre 지도와 지도 입히기. 지침 2와 정면으로 어긋난다. 코드 크기의 대부분이기도 하다
- `src/geo/tiles.ts`, `dem.ts`: 실행 중에 AWS 타일을 받아 합성하는 방식. 구덩이 메우기 같은 땜질도 함께 버린다
- `src/render/terrain.ts`, `water.ts`: 매끈한 지형과 사실적인 수면. 면 기반 표현으로 새로 쓴다
- 30 m 세밀 격자, 데스크톱 옆 패널 화면, 구글 웹폰트

## 배운 것

1. **공개 표고 자료로는 수십 m 단위 침수 계산을 믿기 어렵다.** SRTM은 나무와 건물 높이가 섞여 있다. 센다이 평야에서 해안 1 km 안쪽이 중앙값 3~5 m, 상위 10%는 8~9 m로 찍혀 방풍림이 둑 노릇을 한다. 실제 1.7 m로 평평한 공항 활주로도 −4~+8 m로 출렁인다. 파도는 실제보다 크게 나오는데 내륙 침투는 짧았다(4.1 km, 실제 약 5 km). 세밀한 격자보다 **거친 면 단위의 양식화된 표현**이 자료의 정밀도에 더 맞는다.
2. AWS 지형 타일은 z10까지만 수심이 있다. z11부터 바다는 0 m이고 해안선에 −300 m짜리 가짜 구덩이가 있다.
3. 1차 유한체적법은 먼 거리 전파에서 파고를 크게 깎는다. 엇갈린 격자 + 풍상 면 수심이 전파와 침수를 한 기법으로 다루기에 맞았다.
4. 잠든 격자를 깨우는 판정은 동기식으로 읽어야 한다. 비동기로 하면 계산이 빠를 때 파를 놓친다.
5. 먼 거리에서 파고를 과장해 그리면 골이 해저를 뚫고, 수면 기울기가 수평선을 반사해 회색 띠가 생긴다. 과장에는 상한이 필요하다.
6. 이 개발 환경의 헤드리스 브라우저는 GPU를 못 쓴다. 가장 낮은 해상도로만 끝까지 돌려 볼 수 있다.

## 끝내지 못한 것

- 실제 GPU와 실제 폰에서의 성능 측정
- 침수가 적게 나오는 원인을 가르는 실험(마찰, 잡음 제거, 나무 높이 제거). 돌리기는 했으나 결과를 읽기 전에 임시 폴더가 비워져 값이 없다. 임시 코드는 모두 걷어 냈다
- 재생 속도 컨트롤이 드롭다운이다. 시계 옆 등비 5단계 버튼이 낫다
