# 쓰나미 플레이

지구 위에서 해저 지진이나 소행성 충돌을 일으키고, 쓰나미의 전파와 해안 영향을 살펴보는 웹 시뮬레이터다. 삼각형 면으로 지형과 수면을 표현하고, 계산은 브라우저의 WebGL2 GPU에서 수행한다. 서버는 정적 파일만 제공한다.

현재 개발 대상은 `app/`이다. `src/`에는 이전 프로토타입 2와 현재 앱이 재사용하는 물리·좌표 모듈이 있다. 모바일 사용을 목표로 개발 중이며, 실제 폰 성능 측정은 남아 있다.

## 실행과 검사

```bash
npm install
npm run app:dev       # 현재 앱: http://localhost:5190
npm run app:build     # 타입 검사 + 현재 앱 빌드 → app/dist
npm run app:preview   # 빌드 결과 미리보기
npm run typecheck
npm test              # 현재 앱과 공통 물리 모듈 등의 단위 테스트
npm run test:e2e      # 현재 앱과 프로토타입의 브라우저 검사
```

브라우저 검사를 처음 실행할 때는 `npx playwright install chromium`이 필요하다. `npm run test:e2e:gpu`는 WSLg와 Mesa d3d12를 사용하는 실제 GPU 검증 환경용이다([D-041](docs/decisions/DECISIONS.md#d-041-검증은-wslg-창에-mesa-d3d12-드라이버를-강제해-실제-gpu로-돌린다-2026-09-23)).

`npm run dev`, `npm run build`는 이전 프로토타입용이다. `npm run check`의 빌드 대상도 프로토타입이므로 현재 앱 빌드는 `npm run app:build`로 확인한다.

## 현재 사용 흐름

1. 지구를 회전·확대하고 바다를 눌러 발생원을 놓는다. 해저 지진의 규모·단층 방향 또는 소행성의 크기·속도·재질을 조절한다. 지진 규모는 7.5~10.5이며, 단층 크기를 고정한 채 규모에 맞춰 미끄러짐을 바꾼다. 새 시나리오의 기본 단층은 약 614 × 189 km이며, 9.5 초과는 가상 실험으로 표시한다. 공유 링크에는 단층 크기도 포함한다. 지진은 초기 수면 변화를 미리 보고, 소행성은 충돌 전까지 잔잔한 수면과 충돌 위치를 표시한다.
2. 필요하면 침수를 계산할 해안을 고른다. 쓰나미를 일으키면 자료와 격자를 준비하고 시각 0에서 멈춘다. 재생 단추를 누르면 시작 효과와 함께 계산이 진행된다.
3. 지구 위에서 파도의 전파, 해안의 침수 표현, 영향받는 도시를 살펴본다. 선택한 해안에서는 침수 면적과 처오름 등 계산 통계도 표시한다.
4. 배속과 시간 슬라이더로 시각을 바꾸고, 발생원을 수정하거나 같은 시나리오를 다시 실행한다. 링크를 복사하면 발생원과 관측 해안 설정을 공유할 수 있다. 되감기는 처음부터 다시 계산한다.

해수면 상승 슬라이더나 숫자 입력으로 기본 수위를 0~1,000 m 올릴 수 있다. 높아진 수위는 해안 모양과 계산 수심에 반영되며 공유 주소에도 저장된다. 수위를 바꾸면 진행 중인 계산은 초기화된다.

지형과 수면은 색상 또는 와이어프레임으로 볼 수 있다. 실제 해안선·국경과 주요 도시를 켜고 끌 수 있다. 파도 높이는 지형과 동일, 자동, 과장 버튼으로 고르며 기본값은 ‘자동’이다. 배속은 슬라이더나 숫자 입력으로 1~3,600배를 지정하고, ‘최대’ 버튼으로 가능한 가장 빠르게 계산한다.

## 언어

첫 방문의 기본 언어는 영어이며 상단에서 한국어·영어를 전환할 수 있다. 언어를 바꿔도 진행 중인 계산은 유지된다. 주소의 `?lang=ko` 또는 `?lang=en`으로 언어를 지정할 수 있으며, 선택은 브라우저에 저장되고 공유 링크에도 포함된다. 번역을 추가하는 방법은 [다국어 UI](docs/I18N.md)를 참고한다.

## 배포와 검색 노출

Cloudflare Pages에서는 저장소 루트를 기준으로 빌드 명령 `npm run app:build`, 출력 폴더 `app/dist`를 지정한다. 지형 자료도 빌드에 포함되므로 별도 서버는 필요 없다.

배포 환경 변수 `SITE_URL`에 최종 공개 주소를 설정한다(HTTPS를 포함하고 쿼리·해시는 제외). 빌드가 대표 주소(canonical), Open Graph·Twitter 공유 이미지의 절대 주소, `sitemap.xml`, 사이트맵 위치를 포함한 `robots.txt`를 생성한다. 시나리오별 쿼리 주소는 대표 주소로 통합한다. `SITE_URL`이 없으면 주소를 추측하지 않고 해당 메타데이터와 사이트맵 생성을 생략하며 빌드 경고를 남긴다. Cloudflare의 매번 달라지는 미리보기 주소 대신 최종 공개 주소를 사용한다.

검색 제목·설명과 접어서 볼 수 있는 소개·사용법은 초기 HTML에도 들어 있다. 공유 카드는 기본 언어인 영어로 제공한다. 이미지 원본은 `app/public/og-image.png`이며, 앱 외관이 바뀌면 `npm run app:build` 후 `node scripts/generate-social-image.mjs`로 재생성하고 다시 빌드한다(Playwright Chromium 필요).

배포 후 `/robots.txt`, `/sitemap.xml`, `/og-image.png` 응답을 확인하고 Google Search Console에서 도메인 또는 URL 소유권 확인 후 사이트맵을 제출한다. 도메인을 바꾸면 `SITE_URL`도 바꾸고 다시 배포한다.

## 계산과 지형

| 구분 | 현재 앱의 방식 |
|---|---|
| 전파 | 전 지구 약 39 km 격자와 발생원 주변 약 8 km 격자, 비선형 천수방정식과 단방향 중첩 |
| 선택한 해안 | 중간 격자를 거쳐 약 480 m 격자에서 젖음·마름과 침수를 직접 계산 |
| 그 밖의 해안 | 앞바다 파고에서 경험식으로 처오름·침수 범위·도달 시간을 추정해 표시 |
| 지형 | 자체 호스팅하는 약 39 km 전 지구 자료와 필요할 때 받는 약 10 km 자료 조각. 더 세밀한 표현에는 보간과 생성한 지형을 사용 |
| 렌더링 | WebGL2로 지형과 물을 별도 삼각형 메시로 표시. 보는 거리에 따라 세분화 |

격자 간격은 위도에 따라 달라진다. 약 480 m는 위도 38도 부근의 값이다. 계산 격자와 화면의 삼각형을 잘게 나누어도 원자료의 실제 해상도가 높아지는 것은 아니다.

## 현재 한계와 남은 작업

- 기본 모드의 침수는 거친 자료와 생성한 지형 위의 양식화된 표현이다. 항만·제방 등 실제 연안 구조를 재현하지 못하며 방재 판단용이 아니다.
- 전 지구 계산 범위는 위도 약 ±66도다. 좁은 해협과 만은 거친 격자에서 사라질 수 있다.
- 분산과 쇄파 과정을 직접 풀지 않는다. 큰 소행성의 파고와 침수 추정에는 특히 큰 불확실성이 있다.
- 전체 계산은 자동 정지 조건과 72시간 상한을 쓴다. 선택한 해안의 중간·세밀 격자는 활성화 후 약 3시간까지만 계산한다.
- 실제 데스크톱 GPU 검증 기록은 있지만, 실제 폰의 속도·메모리·되감기 응답은 아직 측정하지 않았다.
- 실제 세밀 지형을 별도로 받아 계산하는 상세 모드는 보류 중이다.

남은 작업과 완료 기준은 [계획](docs/PLAN.md), 전송량 상한은 [다운로드 예산](docs/DATA-BUDGET.md), 기존 실측은 [측정 기록](docs/DATA-MEASUREMENTS.md), 변경 이유는 [결정 이력](docs/decisions/DECISIONS.md)에 있다.

## 폴더

```text
app/src       현재 앱: 지구 화면, 지형, 자료 로더, GPU 계산, 침수 판정
app/public    자체 호스팅하는 지형·경계선·도시 자료
scripts       자료 생성 스크립트
src/physics   현재 앱도 재사용하는 발생원 모형과 CPU 기준 솔버
src/geo       좌표 모듈과 이전 프로토타입의 격자·지형 처리
src/app       이전 프로토타입의 화면과 시뮬레이션 조립
src/gpu       이전 프로토타입의 GPU 솔버
src/render    이전 프로토타입의 three.js 렌더링
src/picker    이전 프로토타입의 2D 지도
tests        단위 테스트와 브라우저 검사
dev          검증 페이지, 측정·스크린샷 스크립트
```

이전 프로토타입은 [실행과 구현](docs/PROTOTYPE-V2-USAGE.md), [종료 당시 정리](docs/PROTOTYPE-V2.md), [작업 기록](docs/tasks/README.md)을 참고한다.
